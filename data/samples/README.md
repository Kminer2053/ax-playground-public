# data/samples — 온보딩용 샘플 데이터

기관 무관(중립) 샘플이라 어느 기관이든 그대로 넣고 시작할 수 있습니다.

## quiz-sample.csv — AI 리터러시 퀴즈 20문항

4지선다 14문항 + O/X 6문항(O/X는 보기1·2만 사용). UTF-8 BOM 포함이라 엑셀에서 바로 열립니다.

이 CSV는 관리자 화면 **업로드 형식을 보여주는 예시 20문항**입니다. 본팩(기관 중립 기본팩
200문항)은 `scripts/quiz-seed-data.json` 이며 `npm run seed:quiz` 로 일괄 시드합니다.

넣는 방법: `/admin` 접속 → **퀴즈 관리** 탭 → **엑셀/CSV 일괄** 버튼 → 이 파일 업로드.

직접 문항을 만들 때는 같은 화면의 **CSV 양식** 버튼으로 템플릿을 받아 작성하세요
(헤더: `문제,보기1,보기2,보기3,보기4,정답번호,해설`, 정답번호는 1부터).

## library-posts.json — 프롬프트 도서관 샘플 게시물 6건

보고서 요약·회의록 정리·엑셀 수식 등 실무형 프롬프트 예시입니다.

넣는 방법:

```bash
npm run seed:library-sample
```

같은 제목의 게시물이 이미 있으면 건너뛰므로 여러 번 실행해도 안전합니다(멱등).
접속 정보는 `.env.local` 의 `MONGODB_URI` 를 사용합니다.
