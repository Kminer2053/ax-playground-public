## A. 업종별 매출트렌드 분석 — `/panel/sales/trend`

업로드/예측은 **"데모 데이터로 미리보기"** 또는 실제 엑셀로 확인.

- [ ] **(C) 인쇄·PDF 버튼** — 분석 결과 화면 상단에 `인쇄·PDF` 버튼이 있고, 누르면 인쇄 다이얼로그가 뜬다. (기존엔 편의점에만 있었음)
- [ ] **(C) 금액 단위 배지** — 화면 헤더에 `단위 : 천원` 배지가 보인다.
- [ ] **(C) 역 변경** — 역 선택 후 상단 역 칩 옆 `역 변경` 버튼 → 누르면 역 검색으로 돌아가 **새로고침 없이** 다른 역으로 바뀐다.
- [ ] **(C) 업종 드롭다운 정리** — 업종 필터 목록에 매출 0인 업종(상생물류·임대·기타수익 등)이 **안 보인다**.
- [ ] **(C) 참고용 매출 예측 보기 — 깜빡임** — 월별 탭에서 `참고용 매출 예측 보기` 체크 → 그래프가 **떴다 사라지지 않고** 바로 그려진다. 연간 탭도 동일.
- [ ] **(C) 예측 그래프 표시** — 체크 시 예측 막대(실적+잔여추정 스택) + 표가 뜬다.
- [ ] **(C) 예측 데이터 부족 폴백** — 당월/당해 누계가 없고 과거 실적만 있어도 예측이 그려진다. 과거 실적조차 없으면 빈 차트 대신 **"예측에 필요한 실적 데이터가 부족합니다"** 안내 카드가 뜬다.
- [ ] **(C) 첨부 유지 — 화면 이동** — 엑셀(일자별/월별/연도별, 전문점 일자별/월별) 첨부 후 다른 화면 갔다 와도 첨부가 남아 있다.
- [ ] **(C) 첨부 유지 — 하드 새로고침** — 첨부 상태에서 **F5(새로고침)** 해도 첨부가 남아 있다.
- [ ] **(C) × 삭제 버튼** — 첨부된 슬롯 **우상단 × 버튼** → 그 첨부만 삭제된다. (전문점 슬롯은 해당 종류 첨부 전체 삭제)
- [ ] **(C) 전문점 분석 — 최대 감소/최저 성장** — 상단 `전문점` 탭에서 특정 역 선택 시, 요약 카드에 `최대 감소 ○○`(하락 있을 때) 또는 `최저 성장 ○○`(하락 없을 때)가 **빈칸("-") 없이** 항상 값으로 표시된다.
- [ ] **(C) 확장분석(사내 매출시스템 원본형) — 본부·공급처 강조** — 원본형 데이터 분석 화면에서 PB상품·계약구분 같은 전매장 공통 섹션이 **없고**, 본부별·공급처별 매출만 강조된다.
- [ ] **(L) 자연어 검색** — 자연어 질문(예: "서울역 업종별 매출 비중") 시 내부망 LLM 경유로 응답. *(LLM 실패 시 규칙 파서로 폴백)*

## B. 편의점 매출 비교분석 — `/panel/sales/compare`

업로드·분석은 브라우저에서 직접 처리(LLM/DB 불필요).

- [ ] **(C) 매출 엑셀 다운로드 방법 순서** — `📥 다운로드 방법` 가이드 클릭 → 가이드가 업로드 박스와 같은 순서로: **① 우리 매장 일매출 → ② 현재고 → ③ 비교 매장 일매출 → ④ 전체 통계**.
- [ ] **(C) 첨부 유지 — 뒤로가기** — 엑셀 4종 첨부 → `분석 시작` → 결과 → `← 새 파일 업로드`(뒤로) → 첨부가 남아 있다.
- [ ] **(C) 첨부 유지 — 화면 이동·하드 새로고침** — 다른 화면 갔다 와도, **F5** 후에도 첨부가 남아 있다. 매장 선택(우리/비교 드롭다운)도 유지된다.
- [ ] **(C) × 삭제 버튼** — 각 업로드 박스 **우상단 × 버튼** → 그 파일만 삭제된다.
- [ ] **(C) 엑셀 이상 사전 경고** — 일별 매출이 비정상적으로 균일한(잘못 받은) 엑셀이면 결과 화면에 **"일별 매출 추이가 비정상적으로 균일합니다…"** 경고 배너가 뜬다.
- [ ] **(C) 금액 단위 배지** — 결과 헤더에 `단위 : 천원`.
